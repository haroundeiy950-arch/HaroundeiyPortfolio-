## Requirements
Install a current Node.js LTS release and Git. Then run:

```powershell
npm install
npx expo install --fix
npx expo start
```

For web preview, run `npx expo start --web`. Camera functionality requires a supported physical device; web browsers may handle media permissions differently.

## Project structure
- `src/components/` reusable UI components
- `src/navigation/` bottom navigation
- `src/screens/` app screens
- `src/storage/` AsyncStorage persistence
- `src/theme/` colors and spacing
- `src/types/` TypeScript models
- `src/data/` skill and project content
- `docs/` submission documentation and evidence checklist
